# Estudos-Java

## Comandos 

Configure `OPENROUTER_API_KEY` no arquivo `.env` na raiz do projeto antes de iniciar a aplicação. O Spring Boot carrega esse arquivo ao rodar localmente; no Docker Compose, a chave também é encaminhada ao container.

### Para rodar o programa
```powershell
mvn spring-boot:run
```

Acesse: 
http://localhost:8080/login.html
